# Linux-Operations
The purpose of the linux operation projects is to learn:
- Shell commands
- Files/directories
- System calls
- Basic Linux tooling
- Permissions
- Kernel Modules/Drivers

The projects below have a lot of overlap with one another as far as the lessons goals are so I did not mention them:
- Fibanocci-Kernel-Driver: A kernel module that spits out a fibinaci sequnce into dmesg
- mod-cp: Modifed version of cp command where you can copy multiple versions of a file
- mod-ps: Modified version of ps command where you can certain stats on specific processes
- secure-rm: Modfied version of rm command that overwrites files with random data multiple times, ensuring they cannot be recovered.
